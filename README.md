# GL Strategic — Sitio Web Corporativo

Sitio web corporativo de **GL Strategic**, consultora de gestión estratégica. Sitio estático en HTML desplegado con GitHub Pages (dominio propio vía `CNAME`).

## Contenido

- `index.html` — Página principal
- `noticias.html` — Sección de noticias
- `assets/` — Recursos estáticos (imágenes, estilos)
- `crece360/`, `hec/`, `postal/` — Verticales y proyectos asociados

## Despliegue

El sitio se publica automáticamente con **GitHub Pages** al hacer push a `main`.
